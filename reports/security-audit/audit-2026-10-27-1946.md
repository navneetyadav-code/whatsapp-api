## Attack Surface Inspection Findings

### 1. PHP Gateway & Web Endpoints (`public/`, `src/`)
- **SQL Injection:** All newly added campaign lifecycle and test dispatch handlers in `public/index.php`, `src/lib/MessageQueue.php`, and `src/lib/ContactService.php` use strict prepared PDO statements with bound parameters (`?`). Zero dynamic SQL concatenation.
- **CSRF Protection:** All state-mutating campaign endpoints (`campaign-create`, `campaign-pause`, `campaign-resume`, `campaign-cancel`, `campaign-resend`, `campaign-test-send`) mandate `verify_csrf()` session token verification.
- **File Upload Security:** All media attachment uploads in both the campaign creator and test dispatch console route through `save_uploaded_media()`, which validates MIME magic bytes, enforces a 15MB/20MB size cap, normalizes file paths, and stores media outside direct public script execution paths.
- **PII & Endpoint Protection:** Verified that recipient suppression checks are strictly enforced at the campaign creation and enqueue boundary, preventing messages to opted-out contacts.

### 2. Baileys Worker & Queue Security (`worker/`)
- **Queue Atomicity & Isolation:** All queue ingestion queries preserve `available_at` and `priority` column bindings, ensuring worker queries use `ORDER BY priority DESC, available_at ASC, id ASC` with `FOR UPDATE SKIP LOCKED`.
- **Ephemeral Media Cleanup:** Media uploaded with broadcast campaigns is safely retained until campaign completion or cancellation via `safelyCleanupAttachment()`, preventing orphaned files or premature deletion.
- **Timing Safe Authentication:** Internal worker endpoints enforce `crypto.timingSafeEqual()` for `X-Worker-Token` validation.

### 3. Secret Hygiene
- Verified that no live API keys (`wa_live_...`), database passwords, or personal credentials are committed to tracked files.
- `.env` and sensitive configurations remain strictly quarantined and gitignored.
