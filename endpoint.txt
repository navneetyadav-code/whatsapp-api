1. CLOUD ENDPOINTS (RENDER LIVE SERVER)
--------------------------------------------------------------------------------
Base URL:
  https://whatsapp-api-xepo.onrender.com

1.1 Standard Messaging Endpoint (Recommended):
  POST https://whatsapp-api-xepo.onrender.com/api/send.php

1.2 Meta WhatsApp Cloud API Alias Endpoint:
  POST https://whatsapp-api-xepo.onrender.com/api/messages.php

1.3 Meta Graph API URL Rewrite (Compatible with Meta SDKs):
  POST https://whatsapp-api-xepo.onrender.com/v20.0/{PHONE_NUMBER_ID}/messages
  (Note: You can use ANY version e.g. v20.0, v19.0, and any dummy number ID)

1.4 Gateway Health Check:

3. AUTHENTICATION (SINGLE KEY ARCHITECTURE)
--------------------------------------------------------------------------------
You can pass your API Key using ANY of the following 3 methods:

Method 1 (Header - Standard):
  X-API-Key: wa_live_YOUR_API_KEY_HERE

Method 2 (Header - Meta Cloud API Bearer Token):
  Authorization: Bearer wa_live_YOUR_API_KEY_HERE

Method 3 (Query Parameter):
  https://whatsapp-api-xepo.onrender.com/api/send.php?access_token=wa_live_YOUR_API_KEY_HERE


--------------------------------------------------------------------------------
4. REQUEST PAYLOAD FORMATS
--------------------------------------------------------------------------------

FORMAT A: Standard Flat JSON (Recommended - Simple & Fast)
Headers:
  Content-Type: application/json
  X-API-Key: wa_live_YOUR_KEY

Body:
{
  "to": "919876543210",
  "message": "Hello from WhatsApp API! 🚀",
  "humanize": true
}

--------------------------------------------------------------------------------

FORMAT B: Meta WhatsApp Cloud API Format (Drop-In Replacement)
Headers:
  Content-Type: application/json
  Authorization: Bearer wa_live_YOUR_KEY

Body:
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919876543210",
  "type": "text",
  "text": {
    "preview_url": false,
    "body": "Hello via Meta Cloud API format! 🌐"
  }
}
